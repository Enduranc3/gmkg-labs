# ЛР5. Проекціювання (варіант 1)

Метод 5 — диметрія на площину y = 0. Грановане тіло — ракета: шестигранний корпус,
носова піраміда і три стабілізатори (22 вершини, 45 ребер, 25 граней, V − E + F = 2).

Точка простору множиться на матрицю проекції: [x' y' z' 1] = [x y z 1] · M, де

M = Rx(β) · Rz(α) · M_орт(y = 0).

Ця матриця отримана з формули триметрії методички (5.9) циклічною заміною осей
X → Z, Y → X, Z → Y. Умова диметрії — однакове скорочення осей X та Z, тому кут β
обчислюється за кутом α (формула 5.11):

sin²β = sin²α / (1 − sin²α), тобто sin β = ±tg α, |α| < 45°.

Коефіцієнти скорочення: f_x = f_z = cos α, f_y = √2·|sin α|.

## Можливості

- зміна параметрів тіла: масштаб, висота, ширина, глибина;
- зсув та обертання навколо власних осей, що проходять через центр C усередині тіла;
- анімація: параметр змінюється між мінімумом і максимумом, водночас тіло
  зсувається та обертається на заданий оффсет за кадр;
- зміна параметрів проекції: кут α, знак кута β, готові значення (диметрія
  0,94 : 0,47 : 0,94, ізометрія, вид зверху);
- перетягування сцени мишею, масштаб коліщатком.

## Структура

```
main.py             точка входу
main_window.py      головне вікно
scene_widget.py     сцена: проекція точок, осі, сітка на площині y = 0, тіло, центр C
controls_panel.py   панель керування: параметри, перетворення, анімація, проекція
polyhedron.py       вершини й грані тіла, матриця його положення у просторі
core/matrix.py      матриці перетворень 4×4 і матриця диметрії
```
