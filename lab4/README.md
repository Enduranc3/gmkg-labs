# ЛР4. Побудова гладких криволінійних контурів (варіант 1)

Проєкт ЛР3 (метод 10 — дуги кубічних парабол, контур 30 — хмара з блискавкою та дощем),
доповнений гладкістю 1-го порядку між сусідніми дугами.

Кубічна парабола — це крива Безьє третього порядку з реперними точками A, B, C, D:
r(u) = (1−u)³·A + 3u(1−u)²·B + 3u²(1−u)·C + u³·D, 0 ≤ u ≤ 1.
Умови гладкості 1-го порядку в точці з'єднання дуг r⁽¹⁾ і r⁽²⁾ (формули 4.4, 4.8 методички):
r₃⁽¹⁾ = r₀⁽²⁾ і T = 3(r₃⁽¹⁾ − r₂⁽¹⁾) / α₁ = 3(r₁⁽²⁾ − r₀⁽²⁾) / α₂.

## Типи точок

- **вузлова точка** (чорна) — точка з'єднання, у якій забезпечується гладкість: при зсуві
  крайньої реперної точки однієї дуги протилежна реперна точка сусідньої дуги повертається
  на продовження дотичної, зберігаючи свою відстань до вузла;
- **точка зламу** (червона) — точка з'єднання без умови гладкості: реперні точки рухаються незалежно;
- **реперні точки** (зелені) — інші точки характеристичних ламаних.

При завантаженні точки з кутом між дотичними менше 15° стають вузловими (86 точок),
решта — точками зламу (30: вістря крапель, блискавки, кінці завитків). Подвійний клік по
точці з'єднання або прапорець на панелі перемикає її тип; ставши вузловою, точка
вирівнюється по бісектрисі дотичних. Гладкість зберігається й на кадрах анімації,
з будь-якими k та після евклідових перетворень.

## Можливості ЛР3, що збережені

- контур з 14 замкнених частин, 116 дуг кубічних парабол;
- характеристична ламана та реперні точки, які можна приховати;
- перетягування реперних точок мишею;
- зміна довжини дотичних k, кроку параметра u, точка дуги r(u);
- анімація переходу хмари в сонце;
- зсув та обертання контуру навколо довільної точки P;
- перетягування сцени мишею, масштаб коліщатком.

## Структура

```
main.py                 точка входу
main_window.py          головне вікно
scene_widget.py         сцена: сітка, осі, контур, ламана, рухомі точки, подвійний клік
controls_panel.py       панель керування: гладкість, параметри дуг, анімація, перетворення
contour.py              рівняння дуги, умови гладкості, редагування, анімація
figures.py              кінцева фігура анімації (сонце), дуги у формі Фергюсона
contour_data.py         реперні точки контуру №30
core/matrix.py          матриці перетворень (з ЛР1)
tools/trace_contour.py  оцифрування контуру з PDF завдання ЛР3 (потрібні PyMuPDF, numpy)
```

## Запуск

```bash
pip install -r requirements.txt
```
