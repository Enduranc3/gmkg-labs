# ЛР3. Моделювання криволінійних контурів (варіант 1)

Метод 10 — дуги кубічних парабол, контур 30 — хмара з блискавкою та дощем.

Кубічна парабола — це крива Безьє третього порядку з реперними точками A, B, C, D:
r(u) = (1−u)³·A + 3u(1−u)²·B + 3u²(1−u)·C + u³·D, 0 ≤ u ≤ 1. Параметр дуги —
коефіцієнт довжини дотичних k: B' = A + k·(B − A), C' = D + k·(C − D).

## Можливості

- контур з 14 замкнених частин, 116 дуг кубічних парабол;
- характеристична ламана та реперні точки, які можна приховати;
- перетягування реперних точок мишею (вузлова точка тягне за собою сусідні);
- зміна довжини дотичних k для вибраної дуги або для всіх дуг,
  зміна кроку параметра u, точка дуги r(u) при заданому u;
- анімація переходу хмари в сонце (кожна реперна точка рухається по своєму відрізку);
- зсув та обертання контуру навколо довільної точки P;
- перетягування сцени мишею, масштаб коліщатком.

## Структура

```
main.py                 точка входу
main_window.py          головне вікно
scene_widget.py         сцена: сітка, осі, контур, ламана, рухомі точки
controls_panel.py       панель керування, анімація
contour.py              рівняння дуги (крива Безьє 3-го порядку), редагування, анімація
figures.py              кінцева фігура анімації (сонце), дуги у формі Фергюсона
contour_data.py         реперні точки контуру №30
core/matrix.py          матриці перетворень (з ЛР1)
tools/trace_contour.py  оцифрування контуру з PDF завдання (потрібні PyMuPDF, numpy)
```
