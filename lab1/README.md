# ЛР1. Лінійні перетворення (варіант 1)

Система моделювання плоскої деталі з евклідовими, афінними та проективними перетвореннями.
Python + PySide6; усі перетворення реалізовано власноруч матрицями 3×3 (`core/matrix.py`).

## Можливості

- побудова деталі за кресленням варіанту 1, координатні осі з сіткою (1 клітинка = 10 мм);
- зміна 14 розмірів деталі, контур автоматично перебудовується без розривів;
- зсув, обертання навколо довільної точки P;
- симетрія відносно довільної точки S, масштабування відносно заданого центру;
- афінне перетворення системи координат (X, Y, O);
- проективне перетворення системи координат (Xend, Yend, O та ваги wX, wY, w0);
- перетягування сцени мишею, масштаб коліщатком.

## Структура

```
main.py             точка входу
main_window.py      головне вікно
scene_widget.py     сцена: сітка, осі, деталь, ланцюжок перетворень
controls_panel.py   панель керування
detail_model.py     параметрична модель деталі
core/matrix.py      матриці перетворень (формули 4–17 методички)
core/primitives.py  відрізки, дуги (крок 1°), кола
```

## Запуск

```bash
pip install -r requirements.txt
python main.py
```
