# ЛР2. Побудова чудових кривих (варіант 1 — Декартів лист)

x³ + y³ = 3axy, у полярній СК: r = 3a·cosφ·sinφ / (cos³φ + sin³φ), 0 ≤ φ ≤ π.

## Можливості

- побудова кривої, осі координат та сітка на чотири чверті (1 клітинка = 1 см);
- параметр a за замовчуванням 2 см, ручна зміна під час роботи;
- анімація: автоматична зміна a в заданих межах, рух точки по кривій;
- дотична та нормаль у довільній точці (кут φ), асимптота x + y + a = 0;
- розрахунки: довжина дуги та петлі, площа петлі, площа між кривою та асимптотою,
  радіус кривини, пошук точок перегину;
- зсув і обертання кривої (разом з усіма прямими) навколо довільної точки P;
- перетягування сцени мишею, масштаб коліщатком.

## Структура

```
main.py             точка входу
main_window.py      головне вікно
scene_widget.py     сцена: сітка, осі, крива, прямі
controls_panel.py   панель керування, анімація, вивід розрахунків
folium.py           рівняння кривої, похідні, розрахунки
core/matrix.py      матриці перетворень (з ЛР1)
core/numeric.py     метод Сімпсона, чисельна похідна
```
